| Path                                                                                                                          | What it holds                                                                                                                                                                                                                                                                                                      |
| ----------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `apps/server`                                                                                                                 | The Rust server (axum), crate `rust-next`, binary `server`. Schema in `src/db/schema.rs` and `src/db/migrate.rs`, the realtime hub in `src/ws/`, REST handlers in `src/api/`, the OpenAPI registry in `src/api/openapi.rs`, the access gate in `src/api/access.rs`, the docs site serving in `src/server/docs.rs`. |
| `apps/web`                                                                                                                    | The Next.js 16 client. Store in `app/lib/store.ts`, API client in `app/lib/api.ts`, theme tokens in `app/globals.css`, platform adapters in `app/lib/platform/`, P2P in `app/lib/p2p/`.                                                                                                                            |
| `apps/desktop`                                                                                                                | The Tauri shell for the desktop and mobile apps (`src-tauri`), its shared Rust (`core`) and plugins.                                                                                                                                                                                                               |
| `crates/wasm`                                                                                                                 | Shared Rust compiled to WebAssembly for the web client.                                                                                                                                                                                                                                                            |
| `crates/perms`                                                                                                                | The permission rules, shared by the server and the client.                                                                                                                                                                                                                                                         |
| `crates/profanity`, `crates/identity`, `crates/fed`, `crates/pow`, `crates/automation`, `crates/app-docs`, `crates/app-sheet` | The profanity matcher, sign-in rules, the instance protocol, proof of work, automations and the apps' documents and sheets.                                                                                                                                                                                        |
| `proto`                                                                                                                       | Protocol buffer definitions.                                                                                                                                                                                                                                                                                       |
| `assets`                                                                                                                      | Data files the server and the client share, such as `perm_bits.json`, `p2p_limits.json` and `stun_servers.json`.                                                                                                                                                                                                   |
| `deploy`                                                                                                                      | The scaled Compose example, Kubernetes manifests, nginx config, the separate PeerJS server and the container start script.                                                                                                                                                                                         |
| `docs`                                                                                                                        | This site (Starlight). `docs/generated` holds the OpenAPI and command line descriptions, and `docs/scripts` the generators of the reference pages.                                                                                                                                                                 |
| `scripts`                                                                                                                     | Release scripts, tests of the build files and browser checks.                                                                                                                                                                                                                                                      |
| `jfiles`                                                                                                                      | The `just` recipes. `just --list src` lists them.                                                                                                                                                                                                                                                                  |
| `packaging`                                                                                                                   | Package manager manifests (AUR, Homebrew, Scoop, winget).                                                                                                                                                                                                                                                          |

## Shared logic

Hosted servers and P2P rooms have the same features. Logic that is the same for both lives once: in Rust under `crates/`, used natively by the server and through `crates/wasm` by the client, or in one TypeScript module under `apps/web/app/lib`.
