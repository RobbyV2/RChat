RChat is a chat app with servers, channels and roles, direct messages and friends, voice and video calls, and P2P rooms that live on their members' devices. An instance is one server that serves the app, the API, realtime connections and these pages from one address. Outside services (email, tracking, third-party APIs) stay out unless you set one up.
