title: RChat
description: Chat servers, direct messages, calls and P2P rooms that you run yourself.
---

RChat is a chat app with servers, channels, roles, direct messages, voice and video calls, and peer-to-peer rooms. One instance serves the app, the API and these pages from one address.

- The [settings reference](/docs/reference/settings/) lists every server setting with its default and range.
- The [permissions reference](/docs/reference/permissions/) lists the role permission bits.
- The [command line reference](/docs/reference/command-line/) lists the server's commands and flags.
- The [REST API reference](/docs/reference/api/) lists every endpoint.
